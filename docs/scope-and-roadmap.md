# Scope and roadmap

## Current scope

- Repository and profile navigation.
- GitHub Wiki reference material on engineering and software-house practices.
- Links to selected, documented showcase repositories.

## Out of scope

- A deployed portfolio application, customer portal, or commercial service.
- Publishing private/client data, secrets, active infrastructure details, or unsupported production claims.
- Changing external links, GitHub profile settings, or branding as part of documentation-only work.

## Curation roadmap

1. Keep the selected full-stack and DevOps showcases documented and reviewable.
2. Define concise case-study summaries for only the strongest examples.
3. Review lower-priority labs for archive, consolidation, or inclusion based on distinct evidence of skill.
