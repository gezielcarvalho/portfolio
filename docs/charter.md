# Charter

## Purpose

Provide a concise entry point to selected engineering work, professional profiles, and strategic documentation that demonstrates technical depth, delivery discipline, and communication skill.

## Audience and success

Recruiters, collaborators, clients, and mentees should be able to find a small, coherent set of projects and understand the capability each one demonstrates. Success is curated clarity—not a catalogue of every experiment or a claim of active client services.

## Ownership

The owner curates priorities through GitHub Issues and the personal portfolio Project. Changes to public positioning, profiles, or publishing require a separate approved task.
